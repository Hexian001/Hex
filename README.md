# Hivera

Wallet-native AI on a computational hive theme. Pay USDT, spend metered compute credits, route prompts across a multi-engine swarm.

Working brand while **Hivera** vs **Pollinex** is decided. This draft ships the **AI section** first; Nodes / compute marketplace is teaser-only.

## Stack

- Next.js (App Router) + TypeScript + Tailwind CSS

## Develop

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Draft scope

- AI landing hero, swarm story, interactive chat mock, Scout / Forager capacity
- Nodes chamber marked as coming next
- No live wallet, USDT settlement, or LLM backends yet
